# Vault Conventions

Last reviewed: 2026-08-10

- `01_Project/Project Brief.md` owns stable purpose and scope.
- `01_Project/Current State.md` owns the verified live snapshot.
- `02_Algorithm/` owns durable scientific and interface interpretation.
- `03_Decisions/Decision Log.md` records accepted decisions and rationale.
- `04_Sessions/` is optional dated history, not a daily transcript.
- `05_Handoff/Handoff - Latest.md` owns the next actionable state.

Prefer live code and numerical evidence over notes. Label proposed designs as
proposed, and replace obsolete live state rather than appending a diary.
